🎬 视频内容提取 · 本地转录工具 v2

全程在你的浏览器里运行，视频不上传到任何服务器，因此没有文件大小限制。转录完成后，把生成的提示词交给 Claude，即可得到知识点脑图和详细笔记。

① 选择视频 / 音频文件

点击选择或拖拽文件到这里
支持 mp4 / webm / mov / mp3 / m4a / wav 等浏览器可解码的格式
等待选择文件…（首次使用需联网下载模型，之后会被浏览器缓存，可离线用）

② 转录结果

复制提示词后，粘贴给 Claude（claude.ai 或 Claude Code 均可），它会按规范生成 Mermaid 知识点脑图和详细笔记。转录文字已包含在提示词里，无需再上传视频。

卡住了？排查清单

  1. 一直停在"加载模型"：国内网络连不上 huggingface.co——确认"模型下载源"选的是 hf-mirror.com（本版默认）。换源后重新点开始即可。
  2. 进度条走得极慢：浏览器不支持 WebGPU 时会用 CPU，速度慢 5~10 倍。用最新版 Chrome / Edge，并可先换 tiny 模型试跑。
  3. 转录进行中会实时显示已完成百分比、预计剩余时间和已识别的文字；随时可点"停止"保留已完成部分。
  4. 超长视频（1 小时以上）受内存限制，建议先切段：ffmpeg -i in.mp4 -f segment -segment_time 1800 -c copy part_%02d.mp4
  5. 浏览器无法解码的格式（部分 mkv/flv），先转 mp4：ffmpeg -i in.mkv -c copy out.mp4
