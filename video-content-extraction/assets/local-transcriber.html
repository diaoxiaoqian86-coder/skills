🎬 视频内容提取 · 本地转录工具

全程在你的浏览器里运行，视频不上传到任何服务器，因此没有文件大小限制。转录完成后，把生成的提示词交给 Claude，即可得到知识点脑图和详细笔记。

① 选择视频 / 音频文件

点击选择或拖拽文件到这里
支持 mp4 / webm / mov / mp3 / m4a / wav 等浏览器可解码的格式
等待选择文件…（首次使用需联网下载模型，之后会被浏览器缓存）

② 转录结果

复制提示词后，粘贴给 Claude（claude.ai 或 Claude Code 均可），它会按规范生成 Mermaid 知识点脑图和详细笔记。转录文字已包含在提示词里，无需再上传视频。

使用说明

  1. 推荐使用 Chrome / Edge 最新版（支持 WebGPU 加速；不支持时自动回退到 CPU，速度较慢）。
  2. 首次转录需从 huggingface.co 下载模型（tiny 约 40MB、base 约 80MB、small 约 250MB），之后离线可用。
  3. 超长视频（1 小时以上）受浏览器内存限制，建议先用 ffmpeg 切段：ffmpeg -i in.mp4 -f segment -segment_time 1800 -c copy part_%02d.mp4
  4. 浏览器无法解码的格式（如部分 mkv/flv），先转成 mp4：ffmpeg -i in.mkv -c copy out.mp4
